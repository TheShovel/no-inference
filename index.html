no-inference

A purely symbolic conversational engine that answers questions, writes essays, solves math problems, roleplays characters, and holds conversations. No neural networks involved.

Proof of concept Research project Python

Warning. This is not the best this system could be. We know where the gaps are. The pattern matcher could cover more ground, the knowledge base could be thousands of entries deep, the NLG pipeline could produce more natural prose, and the math solver could handle calculus. But building that takes data, testing, and server time we do not have. If this project had the resources to run continuous evaluation and iterate on the knowledge base at scale, it would compete with chatbot services that cost millions to run. As it stands, it is a demonstration that the approach works. We think that is worth something.

How it works

no-inference classifies every query by intent, then routes it to a specialized handler. No neural networks, no GPUs, no model downloads, no API fees.

query → intent detection → handler → knowledge retrieval → response

The best way to have a good conversation is to not use a neural network. -- Ancient proverb, probably

What it does

intent

Intent detection

Regex-based routing that classifies queries into math, roleplay, instruction, factual, and more.

knowledge

Knowledge base

Curated JSON files with question-answer pairs across science, history, technology, coding, and everyday life.

wiki

Wikipedia integration

On-the-fly Wikipedia retrieval with an NLG pipeline that strips formatting artifacts.

templates

Template engine

Context-aware templates with topic extraction from conversation history.

patterns

Pattern matcher

Social and emotional response patterns for greetings, feelings, and chit-chat.

memory

Fact memory

Extracts and stores user-stated facts ("I like pizza") for later recall ("What do I like?").

math

Math solver

Multi-strategy solver for arithmetic, distance-rate-time, percentages, and probability.

roleplay

Roleplay engine

Character personas with in-character responses. Einstein, pirate, Shakespeare, and more.

nlg

NLG pipeline

Five-pass natural language generation: clean, parse, discourse, realize, fluency.

apis

External API layer

Free public API integrations for weather, time, dictionary, exchange rates, and jokes.

poem

Poem generator

Template-based poem generation. Results range from charming to baffling.

guard

False premise detection

Identifies pseudoscience and non-existent concepts before they reach the knowledge base.

Contributing

This project lives on community effort. Ways to help:

  • Add knowledge base entries in JSON format
  • Write conversation patterns for things the system does not handle well
  • Improve the NLG pipeline to produce more natural sentences
  • Generate more Wikipedia-backed entries
  • Fix bugs and write tests

We welcome pull requests. We especially welcome pull requests that add data. The code is simple. The data is what makes it smart.

Research

This project builds on ideas from:

  • ELIZA (Weizenbaum, 1966) -- Pattern-matching conversational AI
  • DrQA (Chen et al., 2017) -- Wikipedia as a knowledge source
  • MT-Bench (Zheng et al., 2023) -- Multi-turn evaluation framework
  • SPUD (Stone et al., 2003) -- Discourse-driven NLG
  • Cyc (Lenat, 1995) -- Curated symbolic knowledge bases
  • AIML/ALICE (Wallace, 2003) -- Pattern-template chatbot architecture
  • Chat-80 (Warren & Pereira, 1982) -- Symbolic NL query processing

AGPL-3.0 -- Proof of concept -- Not production-ready
